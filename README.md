# Minigame 1
## Devlog
Components can be seen as amino acids. Amino acids are organic compounds that each characterizes a unique code. Put the components together and will make up a GameObject. A Gameobject can be seen as a protein, because a singular protein is made up of various coded amino acids. But, protein can bond with other proteins to make up a larger, unique protein/enzyme. This can be seen as a bunch of GameObjects forming a Scene.
